The search bar on the All Games page filters the entire game library as you type, showing matching results in real time. You never have to scroll the alphabetical list to find a specific game — just start typing and it appears.

## How to Use Search

<Steps>
  <Step title="Open the All Games page">
    Navigate to the All Games page from the main navigation menu.
  </Step>
  <Step title="Type in the search bar">
    Locate the search bar at the top of the right sidebar and start typing any part of a game name.
  </Step>
  <Step title="Browse instant results">
    Matching games appear immediately below the search bar as you type — no need to press Enter or click a search button.
  </Step>
  <Step title="Launch your game">
    Click any result in the list to launch that game instantly.
  </Step>
</Steps>

<Tip>
  You don't need to type the full name. Partial searches work great — for example, typing `slope` will surface Slope, Slope 2, SlopePlus, and any other game with "slope" in the name.
</Tip>

<Note>
  Search covers the full game library. Every title available on the All Games page is included in the search index.
</Note>
