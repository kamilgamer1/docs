The More Games section extends the library well beyond the handful of titles on the main featured grid. Here you will find classic standalone games, community-added picks, Eaglercraft Minecraft versions, and a growing list of additional content that did not make it onto the main featured page.

## Notable Extras

Some standout titles available through More Games:

- **Eaglercraft (multiple versions)** — Browser-playable builds of Minecraft, including Alpha 1.2.6, Beta 1.3, Indev, versions 1.5.2, 1.8.8, 1.9, 1.11.2, and more. Each version runs fully offline in a single HTML file — no Java, no launcher.
- **Marble Racer** — A physics-based marble racing game you can play directly in the browser.
- **Super Drome** — A top-down racing game with tight track layouts, available as a standalone page.
- **VVVVVV** — The gravity-flipping precision platformer, faithfully ported to run in the browser.
- **Mario Builder 64** — A fan-made Mario level-creation tool running in the browser.
- **Helios** — An offline browser-based game available as a standalone HTML file.
- **Sandstone**, **Snow Bros**, **Rocket Knight 2**, and other classic arcade and console titles rounding out the catalogue.

<Note>
  The More Games section is actively growing. New titles are added as the site is developed, so check back periodically — a game you have been looking for may have appeared since your last visit.
</Note>
